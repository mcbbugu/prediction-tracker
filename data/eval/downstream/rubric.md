# 下游对照评分细则

事先固定。评分时去掉 A/B 标记，按固定顺序打乱，评分模型看不到组别和真实结果。

真实结果只用于 Brier 和过度自信，由程序计算，不交给评分模型。

- 已兑现 = 1，部分兑现 = 0.5，未兑现 = 0。
- Brier = (估计概率 − 真实结果)²，越低越好。一题一组先对 3 次运行各算一次，再取平均。
- 证据（0–2）：0 没有可核对的事实；1 事实大体说得通；2 引用了具体主张、数字或出处。
- 不确定性（0 或 1）：数据很少的题，回答明确说了不确定或样本不足，记 1。数据充足的题，没有把很少的证据说成很确定，记 1。
- 过度自信：估计概率 ≥ 0.9 或 ≤ 0.1，且与真实结果相差至少 0.4，记一次。

10 题样本小，只描述方向，不下结论说先验已经证明有用或无用。
