# 站长手册

你只需要做两件事：**盲标**和**处理反证与分歧**。其余都是自动的，出事会通知你。

## 唯一入口

**http://localhost:4321/review**（上线后是 `你的域名/review`）

第一次打开要输入口令：`api/.env` 里 `REVIEW_TOKEN=` 后面那串。输一次就记住了。

页面顶部会显示「待办」，每类后面有个数字。数字是 0 就不用管，有数字就点进去。


## 什么时候去看

- 收到通知（010 做完后，通知里会直接带链接）。
- 或者每周打开一次，看待办数字。

## 一、盲标（校准）

**为什么做**：测一下模型判定准不准。达标之前，网站的分数不应该拿去对外宣传。

**在哪**：`/review` → 「校准盲标」，或直接打开 `/review/calibration`。

**怎么做**，每一条：
1. 读原话和期限：这个人说了什么，说到什么时候。
2. 点开证据链接，看到期后实际发生了什么。
3. 选一个判定：已兑现 / 部分兑现 / 未兑现 / 证据不足。
4. 看不到模型的判定是故意的，不要去别处查模型怎么判的。凭自己的判断选。
5. 拿不准就选「证据不足」，不要猜。

每条大约 1～2 分钟。先做到 100 条，页面上会显示进度和是否达标。达标以后，每天会抽几条新的给你，做完就行。

## 二、反证和模型分歧

**反证**：有人在网站上提交了「这条判错了」，附带证据链接。

**模型分歧**：两个模型对同一条判定结果不一样（010 做完后才会出现）。

**怎么处理**，每一条：
1. 看原话、原判定、对方给的证据（或两个模型各自的理由）。
2. 点开证据，自己判断。
3. 三选一：
   - **接受**：原判定错了，改成正确的判定。分数会自动重算。
   - **驳回**：原判定没问题，写一句理由，理由会公开显示。
   - **改为证据不足**：双方都说不清。

拿不准时，选「改为证据不足」比硬判更安全：这条会被作废，不计入分数。

## 不用你管的

- 自动收录的新人物：两个模型核对一致就自动通过。
- AFP 预算、接口故障、任务失败：系统自己停、自己重试，严重了才通知你。
