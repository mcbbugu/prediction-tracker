# 019 生存分析：延迟系数与兑现时间预测

负责人：Cursor
优先级：P0
依赖：022（延迟系数只对「承诺」算）

## 目标

前沿路线第 1 项（`docs/前沿路线.md`）：量化「他一般会迟到多久」，对新承诺给出预计兑现时间和区间。

## 背景

- 主张有说话日 `published_date`、期限 `deadline`、判定和判定证据。改期串 `thread_id` 把同一承诺的多次改口串在一起（v1.3）。
- 计分在 `api/src/scoring/score.ts`，画像旁证在 `api/src/scoring/indicators.ts`。

## 做法

1. **整理成生存数据**（`api/src/scoring/survival.ts`，纯函数）：每条承诺（改期串按整串算一条，从第一次说的日期起）一行：
   - `承诺时长 = 期限 - 说话日`
   - `实际时长`：已兑现的取兑现证据日期 - 说话日；未兑现或待定的是删失数据，删失时间 = 今天（或判定日）- 说话日
   - 部分兑现按兑现计，但标注
2. **延迟比** = 实际时长 ÷ 承诺时长。用 Kaplan–Meier 估计每人的延迟比分布（带删失），输出中位数和 80% 区间。实现自己写（几十行），不引入大型统计库。
3. **分层借力**：样本少于 8 条时，与同领域所有人的分布按样本量加权混合（权重 n / (n + 8)），并标「样本少，参考同领域」。
4. **预测**：对一条待定主张，预计兑现日 = 说话日 + 承诺时长 × 延迟比（中位数及区间）。延迟比的上分位数是无穷（大部分没兑现）时，显示「多数同类承诺至今未兑现」，不给日期。
5. **存储**：新表 `delay_profiles`（人物、领域或全部、样本数、删失数、中位数、低、高、方法版本、计算时间），随 `recomputeScores` 一起重算。
6. **展示**：
   - 人物页画像旁证加一项「延迟系数」：例如「承诺通常在期限的 2.3 倍时间后兑现（1.4–4.0）」，附 Kaplan–Meier 曲线小图（沿用现有图表风格）。
   - 待定主张详情页：「按他的历史，预计 2029 年兑现（2027–2033）」。
   - consult 和 `/v1/prior` 返回 `delay` 字段。
   - 方法页写清：删失怎么处理、借力规则、只基于已收录的承诺。
