# 016 推算带区间、假设和时间对齐

负责人：Cursor
优先级：P1
依赖：011（计算记录复用重放机制）、014（可选，有了就写日志）

## 目标

数据架构第 6 层第 1 点：每个推算值都可复算，有区间、有时间对齐。

## 背景

推算规则见 SPEC「推算规则」；代码在 `api/src/interests/exposures.ts`，财务在 `org_financials`，持股在 `interests`。

## 做法

1. 新表 `estimates`：`id`、`person_id`、`org_key`、`as_of`（对齐的日期）、`inputs`（jsonb 数组：每个数的值、单位、期间、出处证据 id 或 SEC 文件哈希）、`formula`（文字算式）、`value`、`low`、`high`、`assumptions`（文字列表）、`method_version`。
2. 区间规则：
   - 持股比例给了范围，或不同文件说法不同 → 取最小和最大。
   - 地区占比用最细一组；若只能用上级区域估算，区间放宽到 ±50%。
   - 期间错位超过一年 → 按该公司最近两年的营收增速上下调整。
3. 时间对齐：主张上的「说这句话时的利益」，用说话当天之前最近一期的披露算；人物页默认用最新一期。
4. 前端：推算值显示「约 X（Y–Z）」，悬停显示算式、每个输入的出处和期间、假设列表。consult 返回同样字段。
5. 现有推算全部重算一遍，前后对比写进完成记录。
