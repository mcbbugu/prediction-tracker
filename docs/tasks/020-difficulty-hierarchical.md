# 020 难度调整的技能分 + 分层贝叶斯（公式 v2.0）

负责人：Cursor
优先级：P0
依赖：012（命题结构）、021（承诺强度，可选）

## 目标

前沿路线第 2 项：专说稳妥话的人不再虚高；样本少的人向同类借力。

## 背景

- 现行公式 v1.3：每人每领域独立的 Beta 后验，κ=4，半衰期 3 年（`api/src/scoring/score.ts`）。
- 项目规则：改公式时，`score.ts` 版本号、SPEC、方法页、consult 必须同步改。

## 做法

1. **主张难度**（`api/src/scoring/difficulty.ts`）：每条主张给一个参照概率 p₀（「换成一般人说这句话，兑现的可能性」），优先级：
   - 说话时有对应的预测市场或分析师一致预期 → 用它（本任务只留接口，数据源以后接）；
   - 否则用同类命题（012 的 subject/metric 类别 + 承诺时长分段）的全库历史兑现率，按 Beta(1,1) 平滑；
   - 再否则用同领域的总体兑现率。
   p₀ 和来源存在主张上，可复算。
2. **技能分**：每条判定结果 y（兑现 1、部分 0.5、未兑现 0），技能贡献 = y − p₀。人的技能 = 加权平均（沿用时间衰减和改期串 √k 权重）。正数说明他比一般人更敢说而且说中了。
3. **分层贝叶斯**：把每人每领域的兑现率改成三层部分合并：领域 → 角色（创始人/CEO、投资人、研究者、其他，取 `people.title` 的规则映射）→ 个人。用经验贝叶斯估计每层的先验（矩估计即可，不跑 MCMC），保持纯函数、可复算。
4. **输出**：保留原兑现率（作为「原始兑现率」），新增「技能分」（带 95% 区间）和「合并后兑现率」。排名默认按技能分。
5. **版本**：`score.ts` 版本号改为 v2.0；SPEC 的公式一节、方法页、consult 返回字段同步更新；旧版本分数保留在 `scores` 历史里，不覆盖。
6. 改前改后全员对比表：原始兑现率、新合并兑现率、技能分、排名变化。
