# 027 下游 AI 对照实验：先验到底有没有用

负责人：Cursor
优先级：P0
关联 issue：#3

## 目标

验证「先验」能否让下游 AI 判断得更好，而不只是给它更多信息。结果决定后续功能的取舍。

## 做法

1. **题目**（`data/eval/downstream/questions.jsonl`）：10 题，每题是一句库里人物的公开说法加一个问题，例如「马斯克说 X 年底实现 Y，这件事有多大可能按时发生？请给出概率和理由」。组成：
   - 5 题：人物数据充足（≥ 15 条已判定主张）
   - 3 题：人物数据很少（≤ 3 条）——检验 AI 会不会如实说不确定
   - 2 题：说法与本人利益直接相关——检验利益信息有没有被用上
   题目里的说法优先选**已经有结果**的旧说法，提问时把时间设在说话当天（用 `/v1/prior` 的 `as_of`），这样有真实答案可以对照。
2. **两组**：同一个模型、同样的提示词，A 组不给先验；B 组额外给 `/v1/prior?person=&as_of=` 的返回（JSON 原样）。每题每组跑 3 次，取平均，减少随机性。模型用方舟上现有的模型，走 011 的缓存。
3. **评分**（盲评，事先固定在 `data/eval/downstream/rubric.md`）：
   - 准确：给出的概率对照真实结果的 Brier 分数（越低越好）
   - 证据：引用的事实是否正确、是否引用了先验里的具体主张
   - 不确定性：数据少时是否明确说「样本不足」
   - 过度自信：概率 ≥ 0.9 或 ≤ 0.1 却错了，记一次
   由另一个模型评分，评分时去掉 A/B 标记、打乱顺序。
4. **报告**写进完成记录：两组各项均值、逐题对比表，以及 3 个最能说明问题的回答原文片段。不夸大：10 题样本小，只说「方向」。
