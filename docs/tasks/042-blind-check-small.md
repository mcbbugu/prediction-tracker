# 042 小规模人工盲标：AI 判定准不准

负责人：人工标注（用户）+ Claude（准备样本、算结果）
优先级：P0（两周「证明价值」第 2 件，可以和 041 同时进行）

## 目标

第一次用人的判断量一下 AI 的判定：和人一致的比例是多少，错在哪里。这是 H01 的第一轮，小规模，先看有没有大问题，不追求达到 SPEC 的发布门槛。

## 为什么只能人来标

测的是人和模型判定的一致性。AI 来标就没有意义。准备样本和算结果可以由 Claude 做，标注本身只能由人做。

## 做法

1. **Claude 准备样本**：用已有的 `sampleCalibration`（`api/src/scoring/calibration.ts`）从已判定的主张里抽 40 条，按结论分层（已兑现、部分兑现、未兑现、证据不足各约 10 条，不够的层如实少抽），同层内按领域轮流抽。确认 `/review/calibration` 页面能用、只显示原话、期限和证据，不显示模型的结论。
2. **用户标注**：打开 `http://localhost:4321/review/calibration`，每条独立给出判定。预计 1～2 小时，可以分几次标完。看不懂、证据不够的就标「证据不足」，不要猜。
3. **Claude 算结果**：
   - 总体一致率和 Wilson 95% 区间，Cohen's κ
   - 分层一致率（每层条数很少，只作参考）
   - 逐条列出不一致的：原话、模型结论、人的结论、可能的原因（期限理解不同、证据找错、部分兑现的尺度不同……），归成几类
4. **结论写成三档之一**：
   - 一致率区间下界 ≥ 0.8：判定基本可信，后续按 H01 扩到 100 条
   - 0.6～0.8：能用但有系统性问题，下一步修最大的那类错误
   - 下界 < 0.6：判定不可信，暂停对外展示分数，先修判定

## 范围

- 读写：`api/src/scoring/calibration.ts`（只在样本或统计有问题时修）、`src/app/review/calibration/*`（只在页面不能用时修）
- 新建 `data/eval/calibration/2026-10-round1.md`（结果报告）

- [ ] 报告含一致率、区间、κ、不一致逐条及归类
- [ ] 写明落在三档里的哪一档、下一步做什么
- [ ] 通用检查全部通过
