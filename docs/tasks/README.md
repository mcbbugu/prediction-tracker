# 任务库

给 Cursor（以及任何来干活的 agent）的工作入口。人只需要说一句：「看 docs/tasks/README.md，做下一个任务」。

## 怎么领任务

1. 打开 [BOARD.md](BOARD.md)，从「待办」里按顺序取第一条**负责人是 Cursor** 的任务。
2. 把它在 BOARD 里改成「进行中」，然后读对应的任务文件。
3. 做完后在任务文件末尾的「完成记录」写：改了什么、怎么验证的、遗留问题。
4. BOARD 里改成「已完成」，填上提交号。一个任务一次提交。

一次只做一个任务。任务文件写得不清楚、或做到一半发现要改范围外的文件，停下来，在「完成记录」里写明问题，BOARD 标「卡住」，不要自己扩大范围。

## 硬性规则（所有任务都适用）

- 项目背景先读：`SPEC.md`（长期规则，不能违反）、`api/src/README.md`（后端目录）。
- 只改任务文件「范围」里列出的文件。
- 不删数据库行；需要下线数据时改状态并留记录。
- 不重启、不杀正在运行的进程（接口、前端、worker）。
- 不提交工作区里别人未提交的文件；`git add` 只加自己改的文件。
- 提交前必须全部通过：
  - `cd api && bun run typecheck && bun run test`
  - 根目录 `pnpm lint && npx tsc --noEmit -p .`
- 提交说明用中文，写清改了什么、怎么验证的。不要推送。
- 方舟（火山）联网搜索每日预算 3000 AFP；预算或熔断告警就停，不要绕过。
- 界面改动：整体审美、配色、字体、布局风格不变。

## 新增任务

文件名 `NNN-简短英文.md`，照 [_template.md](_template.md) 写，再在 BOARD 加一行。
