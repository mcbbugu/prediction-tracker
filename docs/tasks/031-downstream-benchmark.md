# 031 下游对照实验做成常设基准

负责人：Cursor
优先级：P1
关联 issue：#3
依赖：030（脚本和泄露检测）；019（C 组）

## 目标

030 的结论是「排除泄露后先验不吃亏」，但 10 题、Brier 差 0.016 的配对 bootstrap 95% 区间是 [-0.059, 0.101]，包含 0，逐题 5 胜 5 负，统计上不能说更准。要把实验做大，并让每个流水线版本都跑一次。

## 做法

1. **扩题到 ≥ 50 道无泄露题**，人物 ≥ 15 个，任何一人不超过 20%。新题来源：029 每日扩库新增的已判定主张，先跑泄露检测，只留无泄露的。
2. **统计**：报告各组 Brier 均值、A−B（和 A−C）配对差值的 bootstrap 95% 区间、逐题胜负数。区间不含 0 才写「更准」或「更差」，否则写「无显著差异」。证据分、过度自信同样给区间。
3. **C 组**：019 完成后加入，先验里带延迟系数。
4. **接进评测台（015）**：作为一项指标写进 `data/eval/history.jsonl`，方法页「流水线版本」表多一列「下游 AI Brier 改善（区间）」。
5. 评分模型：有第二个可用模型时自动切换；没有就在报告里写明限制。
