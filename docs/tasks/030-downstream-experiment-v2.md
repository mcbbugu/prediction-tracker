# 030 下游对照实验第二版：排除答案泄露

负责人：Cursor

关联 issue：#3
依赖：027（复用脚本）；019 完成后加一组（见第 4 点）

## 目标

027 的结果（B 组 Brier 0.209 比 A 组 0.159 更差）有一个设计漏洞，要先排除它才能下结论。

## 问题

1. **答案泄露**：10 题都是 2023～2025 年的旧说法，作答模型（ark-code-latest）很可能在训练数据里见过结果，比如 Semi 后来交付了、Robotaxi 后来上路了。A 组可以凭记忆答对；B 组被先验里「历史兑现率很低」拉向基准，反而吃亏。所以这次比的不是「有没有先验」，而是「模型记忆」和「历史基准」谁更准。
2. **单一人物**：数据充足的 5 题全是马斯克。
3. **评分与作答用同一个接入点**。

## 做法

1. **泄露检测**：对每题先单独问作答模型「这件事后来发生了吗？」。答对、而且说得出具体细节的，标为泄露题。报告里把泄露题和非泄露题分开统计。
2. **换题**：补 10 道无泄露的题，优先选结果出在作答模型知识截止日之后的说法（截止日用第 1 步的探测来估）。若库里不够，从按需分析的新人物里选，人物数不少于 4。
3. **评分模型**：换一个与作答模型不同的模型或接入点；不行就在报告里写明这个限制。
4. **加第三组 C**（019 完成后）：先验里加上延迟系数（「他的承诺通常晚多久兑现」）。验证一个假设：只给兑现率会让 AI 过度悲观，给出「会晚、但常常会做到」的信息会更准。
5. 报告：A / B / C 各组在泄露题和非泄露题上分别的 Brier、证据分、过度自信次数；逐题表。仍然只说方向。
