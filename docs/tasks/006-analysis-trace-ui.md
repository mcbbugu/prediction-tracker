# 006 任务页：把分析过程展示出来（前端）

负责人：Cursor
优先级：P0
依赖：005

## 目标

用户在任务页看到 agent 每一步具体做了什么，感受到严谨。

## 做法

页面 `src/app/jobs/[id]/`。保留现有的步骤时间线和 beUI 的 Agent Activity 样式，每一步可展开：

- 搜索：搜索词列表，每个下面是链接（可点）。
- 存档：表格，列出链接、状态、抓取途径、SHA-256 前 12 位（悬停看全）、Wayback 快照链接。
- 核对原话：通过的条目绿色勾，丢弃的灰色并写理由。用户要看到「丢掉了什么、为什么」。
- 到期核对：判定加采信的证据链接。
- 顶部摘要：耗时、搜索次数、存档数、通过与丢弃的条数。
- 完成后：显示「查看人物页」按钮；人物页头部加一个「生成过程」链接，指回这个任务页。

运行中每 2 秒轮询（沿用现有做法），新事件出现时平滑展开，不跳动。

## 硬性要求

整体审美、配色、字体不变，只用现有组件和 `globals.css` 里的语义色。移动端能看。

## 范围

- `src/app/jobs/[id]/*`
- `src/app/p/[id]/page.tsx`（只加「生成过程」链接）
- `src/lib/api.ts`（类型）
