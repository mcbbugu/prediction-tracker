# 033 文案与术语统一

负责人：Cursor
优先级：P1

## 目标

页面文案说法一致、不自相矛盾、不出现内部用语，让第一次来的人看得懂。只改文字和少量展示逻辑，**不改布局、配色、字体、间距**。

## 一、统一术语（先改这个，后面都照它）

在 `src/lib/terms.ts` 建一份术语表，页面文案都从这里引用，避免各写各的。

| 概念 | 统一用词 | 不再使用 |
| --- | --- | --- |
| 产品定位（全站标题、首页、页脚） | 「先验：公众人物说过的话，后来兑现了多少」 | 「给 AI 用的人物仓库」「给 AI 用的可信度层」「公众人物带期限的公开预测，到期后的核对记录」三种说法并存 |
| 结果在本人控制内的话 | 承诺 | 用「承诺」指所有主张（如「改期 1 / 37 个承诺」） |
| 结果不在本人控制内的话 | 预测 | — |
| 两者合起来 | 主张 | — |
| 承诺兑现率 | 靠谱度 | — |
| 预测兑现率 | 判断力 | — |
| 承诺 + 预测合在一起的兑现率 | 合并兑现率 | 「全部（旧）」「是旧口径……不再当作主分数」 |
| 判定由谁做的（全站唯一的说法） | 「AI 判定」；人工裁定过的写「人工复核」 | 「机器核对」「核对层级：机器核对 42 · 人工复核 0」与「AI 判定 · 未经人工校准」并存 |
| 人物怎么进库的 | 「自动收录」；交叉判定一致的写「自动收录 · 两个模型判定一致」 | 「双模型一致」（太像术语） |
| 贝叶斯先验值 | 不在页面上显示 | 「先验 0.433」 |
| 「先验」这个词 | **只当网站名用**（标志、浏览器标签页标题、「先验」后接冒号的定位句）。解释性文案里一律换成具体说法：「兑现率」「历史记录」「分数」「这个人以前说的话准不准」 | 「领域先验」「先验分数」「一套可追溯的先验」「核对先验」「先验库」「人物先验库」「给 AI 用的先验」 |

> 用户确认（2026-10-23）：网站可以叫「先验」，但这个概念太抽象，解释性文案中不应出现。接口名（`/v1/prior`）和代码里的字段名不改。

## 二、逐页问题

### 首页 `/`
1. **示例卡片数字是写死的**：「自动驾驶 · 39.2（80% 区间 22–58 · 18 条已判定）」和马斯克的真实数据（43.3、19 条；靠谱度 52.7）对不上。改成从接口取马斯克当前的真实数据，或删掉具体数字。SPEC 原则：页面上不能有编造的数字。
2. 主标语「辅助你的 Agent 选择相信谁」语句别扭，对普通访客也太技术化。改为：「在相信一句话之前，先查查说话的人以前准不准」。Agent 相关的说法留在第三个功能卡片里。
3. 按钮「核对先验」意思不清，改为「查一个人」。
3a. 首页其余用到「先验」概念的地方照术语表替换，例如：「一句话进去，一套可追溯的先验出来」改为「一句话进去，这个人过去的兑现记录出来」；「领域先验与利益旁证」改为「按领域的兑现率与利益关系」；「人物先验库」改为「人物库」；「算成按领域的先验分数」改为「按领域算出兑现率」。方法页、任务页、人物页同样全部替换。
4. 每张人物卡同时出现「机器核对」和「自动收录 · 未经人工复核」两个标签。卡片上只保留收录方式标签；「AI 判定」改为在列表上方说明一次，不在每张卡片上重复。
5. 图例「70 以上是实心，52–70 是浅色，再低是空心。这一侧还没有判定过的，显示为虚线」改为一句短的：「实心 ≥ 70 · 浅色 52–70 · 空心 < 52 · 虚线：还没有判定」。
6. 只有 1 条已判定就显示 48.7 这样的分数，看起来过于精确。规则不变（有判定就出分），但在条数 < 3 时，「基于 1 条」后面加「参考价值低」。
7. 统计句「已收录 44 位公众人物」下面大半卡片都是「还没有已判定的主张」。在这句后面加上「其中 N 位已有分数」。

### 人物页 `/p/[id]`
1. **自相矛盾**：头部「综合分 43.3」用的就是合并兑现率，紧接着却写「全部兑现率……是旧口径，不再当作主分数」。合并兑现率改名后，说明改为「承诺和预测合在一起算；综合分用的是它」。
2. 「核对层级：机器核对 42 · 人工复核 0」加上「AI 判定 · 未经人工校准」，合并成一行：「42 条判定都由 AI 完成，尚未经人工校准 · 怎么判的 →」。
3. 每条主张后面的「· 机器核对」删掉，页头已经说过一次。
4. 「可信度（一致性） 权重 30% 尚未收集」改为「可信度（一致性）：还在收集，暂不计入综合分」。没收集的时候不显示「30%」。
5. 「改期 1 / 37 个承诺」用的是旧意思（37 是全部主张数）。改成「改期 1 / 37 条主张」，或者只统计承诺，两者选一，和术语表保持一致。
6. 「兑现记录」表里的「先验 0.433」删掉。
7. 每条主张下面的利益标签「美国 · 营收 50.23% / 48.85% / 46.74%」把三年都列出来了。改为只显示说话当年那一条，其余放进悬停提示。
8. 「说话时任SpaceX 创始人」「说话时任特斯拉 董事」中英文之间的空格不一致。统一规则：中文和英文、数字之间加一个空格，中文和中文之间不加。写一个格式化函数，全站人名、职务、机构名都走它。
9. 主张的「结果」里出现「原文称……」「原文显示……」这类模型口吻。展示时去掉这类开头。根本的修法在判定提示词里要求直接陈述事实，用 011 的提示词版本号升一版。
10. 有些主张没有中文译文，直接显示英文（如「Musk claimed drivers would be able to text…」）。没有 `quote_zh` 的，回填译文：模型翻译，写进 `quote_zh`，原文保留在 `quote` 里不动。页面上中文在前，原文可以展开查看。
11. 「变化原因」里「计分规则调整为 v1.3：计算方式调整」意思重复，改为「计分规则升级到 v1.3」。
12. 利益版图里 Anthropic $1.3B 出现两次。查一下是数据重复还是展示时重复：数据重复就交给清理脚本，展示重复就去重。

### 全站
1. 浏览器标签页的标题每页都是「先验 · 给 AI 用的人物仓库」。人物页改为「埃隆·马斯克 · 先验」，主张页改为「主张摘要 · 人物名 · 先验」，其余页面照此处理。
2. 页面加载完以后，HTML 里仍残留「LOADING 正在加载」文字，读屏软件会把它读出来。加载完成后要从无障碍树中移除。
3. 人物职务由模型生成，长短不一（「Google DeepMind联合创始人、Alphabet首席科学家、Isomorphic Labs联合创始人兼首席执行官」）。卡片上最多显示 24 个字，完整职务放进悬停提示；生成职务的提示词也加长度要求。
