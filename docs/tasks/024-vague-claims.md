# 024 模糊表述：收录并按多种定义判定

负责人：Cursor
优先级：P1
依赖：012（命题结构）

## 目标

SPEC「模糊表述」：没有明确阈值的话照常收录，标「模糊」，拆成 2～4 种操作化定义分别判定，报告判定分布。

## 做法

1. 抽取步骤不再丢弃「有期限、无阈值」的话，改为收录并标 `vague=true`（原话逐字核对规则不变）。
2. 结构化步骤：对模糊主张让模型提出 2～4 种操作化定义，每种是一条 012 的命题（主体、指标、阈值、判定来源），并写一句「这种理解的依据」。定义在收录时就固定，不可修改（与 SPEC 数据架构原则一致）。
3. 到期时每种定义各自判定；主张的展示结果是分布：「4 种理解里 2 种算兑现」，并列出每种的结论和证据。
4. 计分：模糊主张不进靠谱度和判断力的分数；画像旁证「可检验度」把模糊主张的比例计进去。
5. 页面：主张标「模糊」，详情页展开各种理解；方法页解释为什么这样处理。
