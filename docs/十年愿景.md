# 十年愿景（2026-10-23 草稿）

## 判断：十年后什么会稀缺

1. **「谁真的说过什么」会稀缺。** 合成音视频足以乱真后，一句话是不是本人说的、原话是什么、什么时候说的，会从常识变成需要证明的事。
2. **「这个人的话值多少」会被机器大规模消费。** 越来越多的决定由 AI agent 代人做：读新闻、筛投资、给建议。agent 需要一个可查询的先验：这个信息源过去有多准。
3. **信任需要可审计。** 人们不会再相信「某机构说这个人可信」，只会相信「这是数据、这是算法、你可以自己复算」。

所以「先验」的十年定位：**公众言论的公证处 + 给 AI 用的信任层。** 前者回答「他说过什么」，后者回答「他的话该打几折」。两者都必须可以被任何人独立验证。

## 可以借力的前沿突破（只列有公开研究基础的）

| 方向 | 研究基础 | 我们怎么用 |
| --- | --- | --- |
| 大模型做预测接近人类顶尖水平 | Halawi 等 2024《Approaching Human-Level Forecasting with Language Models》；ForecastBench 等公开榜单 | 网站自己的预测器（前沿路线第三部分），并在公开榜单上报成绩 |
| 可扩展监督：用 AI 辩论帮人判断 | Irving 等 2018《AI Safety via Debate》及后续实证研究 | 把 010 的双模型交叉判定升级为结构化辩论：一方找兑现证据、一方找未兑现证据，人只看辩论摘要拍板。人工量进一步下降，判定理由更透明 |
| 跨立场共识算法 | X 社区笔记的「桥接」矩阵分解算法（已开源） | 反证与更正：只有被不同立场的人都认可的更正才生效，防止被一方刷票 |
| 内容来源证明 | C2PA 内容凭证标准、证书透明度日志 | 存档与哈希日志（014）对齐 C2PA，让外部工具能直接验证「这段原话出自哪份存档」 |
| 宪法式对齐 | Anthropic《Constitutional AI》（2022） | 把你的价值判断写成一份公开、带版本号的《先验宪章》，所有模型步骤的提示词都引用它；改宪章要留记录。**这就是「你的意志」进入系统的方式** |
| 可验证计算 | 零知识证明、可复现构建 | 远期：任何人可以证明「这个分数就是用公开代码和公开数据算出来的」，不用信任我们的服务器 |

## 三条红线（比功能更重要）

1. **只评价公开言论，不评价人。** 我们给出的是「他关于 X 的公开预测兑现了多少」，不是「他是不是好人」。不做综合人格分、不做社会信用式的总分。
2. **只收公众人物在公共角色里的公开言论。** 不收私人生活，不收普通人；政治人物暂不收录（已在 SPEC）。
3. **系统自己也被评价。** 网站的每个预测、每次改判都公开记录并接受打分。一个评判别人可信度的系统，自己必须是最透明的。

这三条应该写进宪章第一页。它们决定这个产品是「信任的基础设施」还是「舆论武器」。

## 分阶段

| 时间 | 目标 | 衡量 |
| --- | --- | --- |
| 第 1 年 | 做对：AI 与科技领域 1,000 人，五层数据架构和经济层完成，网站自己的预测开始积累 | 判定准确率下界 ≥ 90%；自己预测的 Brier 分数公开 |
| 第 3 年 | 做成标准：consult / MCP 成为 agent 查询信息源可信度的常用接口；扩展到商业、投资、科学领域；数据集开放给研究者 | 外部 agent 调用量；被学术论文引用 |
| 第 10 年 | 做成基础设施：公众言论的来源证明与信用先验，像证书透明度之于 HTTPS 一样，成为默认存在的底层 | 不需要说明「先验」是什么 |

## 现在就该做的一件事

**写《先验宪章》第一版。** 前沿技术谁都能用，真正区分这个产品的是它坚持什么。宪章包括：

- 使命一句话
- 三条红线
- 判定原则：证据优先、不确定就说不确定、相关不说成因果
- 中立性：对所有人同一标准，包括对我们喜欢或讨厌的人
- 自我问责：系统自己的预测与错误全部公开
- 修改程序：谁能改、怎么留记录
